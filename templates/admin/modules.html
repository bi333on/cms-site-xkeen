🔧 Установка новых модулей

Для установки нового модуля:

  1. Создайте папку с именем модуля в CMS_Site/modules/
  2. Создайте файл module.py с классом, наследующим BaseModule
  3. Перезапустите приложение — модуль автоматически обнаружится

Пример модуля находится в modules/analytics/module.py
